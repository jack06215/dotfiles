# noice

[folke/noice.nvim](https://github.com/folke/noice.nvim) replaces the UI for
messages, the command line and the popup menu. Notifications go through
`nvim-notify`.

- One route hides the LSP progress messages of pyright. All other progress
  messages show.
- The plugin does not load in vscode-neovim.

The config is in [`config.lua`](config.lua).
