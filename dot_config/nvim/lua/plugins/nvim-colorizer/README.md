# nvim-colorizer

[NvChad/nvim-colorizer.lua](https://github.com/NvChad/nvim-colorizer.lua)
colors the background of each color code in the buffer with that color.

It reads hex codes (`#RGB`, `#RRGGBB`, `#RRGGBBAA`, `0xAARRGGBB`), color
names, `rgb()` and `hsl()` functions, CSS and Tailwind classes. Sass support is
off.

The config is in [`config.lua`](config.lua).
