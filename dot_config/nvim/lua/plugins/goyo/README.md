# goyo

[junegunn/goyo.vim](https://github.com/junegunn/goyo.vim) is a mode for prose
without distractions. Run `:Goyo` to turn it on or off. The text area is 100
columns wide and 80% of the window high.

In Goyo mode, line wrap, word-boundary wrap and spell check are on, and line
numbers are off. When you leave Goyo, the plugin sets these options back.

[junegunn/limelight.vim](https://github.com/junegunn/limelight.vim) is a
dependency. It dims all paragraphs except the current one while Goyo mode is
on.

The config is in [`config.lua`](config.lua).
