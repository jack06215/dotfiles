# render-markdown

[MeanderingProgrammer/render-markdown.nvim](https://github.com/MeanderingProgrammer/render-markdown.nvim)
shows Markdown headings, lists, tables and code blocks with their formatting,
in the buffer.

[`config.lua`](config.lua) also sets the `markdown` filetype for two kinds of
files: `.mdx` files, and files named `README` with no extension.
