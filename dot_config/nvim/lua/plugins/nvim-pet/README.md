# nvim-pet (off)

This folder has no active spec. [`init.lua`](init.lua) returns an empty table,
and the spec in it is a comment.

The spec would load the local copy of pets.nvim in
[`lua/vendor/pets.nvim/`](../../vendor/pets.nvim/), which shows an animated pet
in a popup. It needs `hologram.nvim` to draw images. To turn it on, remove the
comment marks in `init.lua`.

This folder is for pets.nvim, not for the `pet` snippet tool.
